# online-self-search-picture

대한민국 성인이 본인 사진 한 장으로 공개 인터넷의 동일·유사 이미지 후보를 확인하는 저가형 자동 셀프검색 MVP입니다.

현재 구현은 외부 검색 API나 사진 업로드 없이 전체 사용자 흐름을 검증하는 mock 데모입니다.

## 시작하기

```bash
pnpm install
pnpm dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 검증 명령

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

## 현재 범위

- 모바일 중심 랜딩 페이지
- 본인·성인 확인
- 로컬 사진 선택과 미리보기
- mock 검색 API
- 검색 진행 상태
- 자동 분류된 후보 결과
- 사용자 본인 여부 판정
- 검색 범위와 한계 안내

현재 데모에서는 선택한 사진 파일을 서버로 전송하지 않습니다. API에는 파일명, 크기와 MIME 유형만 전달하며 결과는 고정된 mock 데이터입니다.
