# 안심 업로드

생성형 AI나 인터넷 서비스에 사진·화면 캡처를 올리기 전, 공개하고 싶지 않은 정보를 확인하고 가린 안전한 사본을 만드는 B2C 서비스 MVP입니다.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 검증 명령

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

## 현재 구현 범위

- 새 서비스 방향에 맞춘 랜딩 페이지와 `/protect` 편집 흐름
- JPG, PNG, WebP 이미지 선택 및 로컬 미리보기
- 마우스·터치 드래그를 이용한 가림 영역 추가
- 선택 영역 개별 삭제·전체 초기화
- 원본 해상도를 유지한 가림 처리 PNG 생성·다운로드
- 브라우저 내 이미지 처리와 재인코딩을 통한 메타데이터 제거
- Google Cloud Vision OCR 텍스트 영역 자동 탐지(선택 가능)
- 이메일·전화번호·웹주소·계정명 후보 기본 선택
- 분리된 OCR 단어를 문맥 영역으로 결합
- 한국 주소·주민번호형 식별정보·API 키·비밀번호·인증번호 후보 분류
- Google Vision 얼굴 영역 후보 탐지
- OCR로 읽힌 한국 차량번호 패턴 분류
- 지원 브라우저의 로컬 QR 코드 영역 탐지
- 자동 후보 포함·제외 및 수동 영역 보정
- 기존 `/search` 주소의 `/protect` 전환

자동 탐지를 끄면 파일을 서버로 전송하지 않습니다. 자동 탐지를 켜면 이미지는 Google Cloud Vision의 텍스트·얼굴 분석 요청에만 사용하며 서버·데이터베이스·Storage에 저장하지 않습니다. QR 분석은 지원되는 브라우저 안에서 처리합니다. 모든 탐지 결과는 확정 판정이 아닌 사용자 검토 후보입니다.

## 다음 구현 순서

1. 실제 화면 캡처 데이터셋으로 문맥 분류 오탐·누락 조정
2. 차량번호 전용 영역 탐지 정확도 개선
3. 익명 사용량 제한과 CAPTCHA
4. 탐지 정확도·사용자 선택률 측정

## 남겨 둔 기존 자산

기존 Supabase 익명 인증, 비공개 Storage, RLS, 작업 상태, 자동 삭제 함수와 Google Web Detection 코드는 아직 제거하지 않았습니다. 새 자동 탐지 구조가 확정될 때 재사용 가능한 부분을 선별하고, 불필요한 검색 도메인은 별도 커밋으로 정리합니다.
