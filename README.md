# 안심 업로드

생성형 AI나 인터넷 서비스에 사진·화면 캡처를 올리기 전, 공개하고 싶지 않은 정보를 확인하고 가린 안전한 사본을 만드는 B2C 서비스 MVP입니다.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## 검증 명령

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

## 현재 구현 범위

- 새 서비스 방향에 맞춘 랜딩 페이지와 `/protect` 편집 흐름
- JPG, PNG, WebP 이미지 선택 및 로컬 미리보기
- 마우스·터치 드래그를 이용한 가림 영역 추가
- 선택 영역 개별 삭제·전체 초기화
- 원본 해상도를 유지한 가림 처리 PNG 생성·다운로드
- 브라우저 내 이미지 처리와 재인코딩을 통한 메타데이터 제거
- 기존 `/search` 주소의 `/protect` 전환

현재 1차 편집기는 파일을 서버로 전송하지 않습니다. 자동 개인정보 탐지는 아직 연결하지 않았으며, 사용자가 직접 영역을 지정하는 편집 흐름부터 검증합니다.

## 다음 구현 순서

1. OCR 기반 텍스트 후보 영역 탐지
2. 이메일·전화번호·계정 ID·주소·인증정보 규칙 분류
3. 자동 후보의 선택·해제와 수동 영역 보정
4. 얼굴·차량번호·QR 등 비텍스트 후보 탐지
5. 익명 사용량 제한과 선택적 서버 처리·자동 삭제 연결

## 남겨 둔 기존 자산

기존 Supabase 익명 인증, 비공개 Storage, RLS, 작업 상태, 자동 삭제 함수와 Google Web Detection 코드는 아직 제거하지 않았습니다. 새 자동 탐지 구조가 확정될 때 재사용 가능한 부분을 선별하고, 불필요한 검색 도메인은 별도 커밋으로 정리합니다.
